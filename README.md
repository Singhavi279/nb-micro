# Nivesh Baithak — Micro Landing Page (`nb-micro`)

Vibrant, lightweight investor summit landing page for **Nivesh Baithak 2026** (September 27, 2026 — Bharat Mandapam, New Delhi).

## Architecture

- **`index.html`**: Semantic, accessible markup for Hero with live countdown, Participating Experts section, Ticket Pricing cards, and OTP Registration Modal.
- **`styles.css`**: Vanilla CSS design system with atmospheric dark-themed hero, typography, speaker cards, and responsive layouts.
- **`script.js`**: Consolidated JavaScript covering payment API integration, real-time ticket pricing, dynamic speaker carousel showcase, live countdown timer, and OTP registration flows.
- **`bundle.html`**: Fully inlined, zero-dependency single-file build of the entire landing page.
